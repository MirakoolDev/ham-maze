Rivals

Four ways to draw the other people in the maze, in the style of the art: black cut-out figures with lit edges, a red room, iridescent objects and a soft floating head. Each one is a live render using the same tricks the game can afford, so what you see here is what you would see in a corridor. Drag a figure to turn it.

Cheap to draw

The look is a black body plus an edge glow worked out per pixel, no textures. Twenty rivals cost about the same as the sentries do now.

Edges are teams

The edge colour carries meaning: cyan for rivals, white for you in replays, pink for a friend you invited, orange for whoever is closest to the monolith.

Skins swap one part

Every skin keeps the same silhouette and changes one thing: the head, the object or the edge. Collectible skins stay recognisable and fair.
